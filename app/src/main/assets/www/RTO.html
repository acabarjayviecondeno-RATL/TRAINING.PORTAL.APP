📋 Report Compliance

Who submitted Monthly Plan, Task Plan, and Task Actual for the selected month. Only working days are counted — Sundays, PH holidays, and leave days are excluded.

Daily Submission Calendar
Trainer Monthly Plan Plan Days Actual Days Working Days Leave / Absent SNS Boosting SNS Score Overall Score Status
Select Report Compliance from the menu to load data...

Plan Days / Actual Days = unique submission dates on working days only (Sunday & PH holidays excluded) · Working Days = Mon–Sat excluding PH holidays · Leave / Absent = approved leave days (excluded from % base) · SNS Boosting = TikTok links in the selected month · SNS Score = best SCORE% · Overall Score = average of 4 equal parts (25% each): Monthly Plan (100/0) · Plan days% · Actual days% · SNS Score (0 if none) · Plan/Actual % = days ÷ (Working Days − Leave/Absent), capped at 100%. · Status: Fully compliant ≥80% · On track 50–79% · Needs attention <50% · No submissions = 0%.
